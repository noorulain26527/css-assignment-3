# Sunny Marzipan Website

A clean and responsive website built using HTML5 and CSS3. This project was created to practice frontend development, page structure, layout design, and custom CSS styling.

## 🚀 Features

- Clean and modern layout
- Responsive design
- Navigation bar
- Hero section
- Content sections
- Image integration
- Styled buttons
- CSS hover effects
- User-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
